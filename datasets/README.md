# Datasets

This directory contains documentation and visualizations for the datasets used in this dissertation. The testbed spans 2016–2026 and covers 110 tasks across 569,026 logs.

## Visualizations

- [Course-Level Summary](./course-level-summary-final.html) — An overview of all data sources grouped by category (formal courses, workshops, shared test suites, lab studies, and supplemental), including task counts, task types, environments, and log totals.
- [Exercise-Level Detail](./exercise-level-detail-table.html) — A detailed breakdown of every individual task within each course and source, including semester coverage and per-task log counts.
